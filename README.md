# MarTech Digital Marketing Portfolio

A professional portfolio website showcasing expertise in Marketing Technology (MarTech), digital marketing strategy, and web development. Built with React, TypeScript, and Vite.

## Overview

This portfolio demonstrates the intersection of marketing, technology, and data — featuring case studies, interactive analytics dashboards, and functional MarTech tools including a UTM builder, funnel analyzer, SEO audit checklist, and customer journey mapper.

## Tech Stack

- **Framework:** React 18 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Charts:** Recharts
- **Icons:** Lucide React

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
